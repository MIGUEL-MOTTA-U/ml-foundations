# Machine Learning Foundations
Getting started in Machine Learning with Anaconda, Jupyter and Python.

## Requirements
- Python + 3.14.0
- Conda + 25.9.1

## Building env project with conda

Create the virtual environment with conda
```shell
  conda env create -f environment.yml
```

Activate the built environment with conda

```shell
  conda activate sandbox
```
